# Support

Use this repository for questions about:

- text-to-video pipeline
- TTS narration
- material indexing and semantic retrieval
- Remotion templates
- editable timeline projects
- render/export behavior

Before asking, provide:

- command used
- input text or sanitized sample
- project JSON path if relevant
- model/embedding backend without secret values
- error output
- whether the issue is planning, TTS, retrieval, resolver, Studio preview or render

Do not paste provider keys, Sub2API keys, private footage links or sensitive generated outputs.
